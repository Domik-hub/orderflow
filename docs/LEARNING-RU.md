# OrderFlow и навыки Java backend

OrderFlow - учебный backend магазина. Покупатель добавляет товары в корзину и оформляет заказ. Администратор меняет каталог и остатки, отмечает заказ отправленным. Оплаты и настоящей доставки здесь нет.

## Разбор оформления заказа

Сначала блокируется строка пользователя: его корзина не может измениться посреди оформления. Затем проверяется ключ запроса. Если заказ уже создан, возвращается он; новая корзина остаётся нетронутой. Если с тем же ключом пришёл другой адрес, API возвращает 409.

Дальше читаются позиции корзины, а товары блокируются по возрастанию ID. Единый порядок уменьшает риск взаимных блокировок. Данные товара впервые загружаются после получения блокировки: чтение Entity до блокировки может оставить в контексте Hibernate старый остаток.

Цена берётся из PostgreSQL. В заказ копируются название, артикул и цена; изменения каталога не переписывают историю покупок. Если второго товара не хватает, исключение откатывает и списание первого товара. Корзина также сохраняется.

## Что хранится в Redis

Только карточка товара: ID, название, артикул, цена, валюта и активность. Остаток читается отдельно из PostgreSQL. Запись живёт 60 секунд. После изменения товара кеш удаляется только после commit.

Инвалидация не делает кеш строго согласованным: одновременное чтение может сохранить старую карточку, а при недоступном Redis удаление может не выполниться. TTL ограничивает срок хранения этой записи. Поэтому оформление заказа не доверяет кешу. Это важное ограничение, которое нужно уметь объяснить.

## Запуск и самостоятельная практика

1. Запусти локальный профиль по README и выполни `scripts/demo.ps1`.
2. Найди в Swagger запрос оформления. Повтори его с тем же UUID, затем с другим.
3. Измени цену после покупки и проверь, что сумма старого заказа сохранилась.
4. Запусти `verify`, прочитай тест гонки за последнюю единицу товара.
5. При наличии Docker выполни `-Pcontainers verify`: контейнеры создаются и останавливаются автоматически.
6. Посмотри тест, который специально подставляет неверную цену в Redis и проверяет правильную сумму заказа.
7. Самостоятельно добавь категорию товара через миграцию V2 и фильтр по ней.

**OrderFlow - Order and Inventory REST API**

Java 17, Spring Boot, PostgreSQL, JPA/Hibernate, Flyway, Redis, Spring Security/JWT, JUnit, Mockito, Testcontainers, Docker Compose, OpenAPI, GitHub Actions.

- Transactional checkout with inventory updates, immutable price snapshots and user-scoped idempotency keys.
- Concurrent-request tests for overselling prevention, duplicate checkout and stock restoration on cancellation.
- Redis product cache with TTL, post-commit invalidation and database fallback.
- HTTP integration tests against PostgreSQL and Redis using Testcontainers and GitHub Actions.
